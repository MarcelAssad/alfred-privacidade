Política de Privacidade — Alfred

O Alfred é um assistente pessoal de uso privado, criado e usado exclusivamente pelo seu responsável (marceldoelinger@gmail.com). Não é oferecido ao público.

Dados acessados

Com autorização do próprio usuário, o Alfred acessa:

  • o Google Agenda, para ler, criar, alterar e cancelar eventos;
  • o Gmail, para ler, arquivar e marcar mensagens como lidas, e para enviar alertas apenas ao próprio usuário.

Uso dos dados

Os dados são usados somente para organizar a agenda e os e-mails do próprio usuário. Trechos de eventos e e-mails são processados pelo serviço de inteligência artificial Claude, da Anthropic, apenas para gerar as respostas do assistente.

Compartilhamento

Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Armazenamento

Os dados ficam no computador do próprio usuário, com acesso restrito.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
